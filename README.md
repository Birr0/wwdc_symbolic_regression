# WWDC symbolic regression: reproduction project

**Review release:** source, saved candidate equations, tests, and reproduction
instructions are included. The exact embeddings, checkpoint/configuration,
and archived spectrum splits are external inputs whose public download
locations are still being prepared. You can install the package and run the
tests without them; reproducing the paper's numerical results requires them.
See [release status](docs/RELEASE_STATUS.md) for the current scope and limits.

**Start here:** [reproduction walkthrough](docs/QUICKSTART.md),
[understand the code](docs/CODE_GUIDE.md), or [documentation index](docs/README.md).
The walkthrough assumes access to the exact external inputs; public download
locations for the model products are still a release task.

This project reproduces the saved-candidate analysis of the WWDC symbolic
regression paper. The released neural checkpoint is the starting point. Model
training and the generation of `orig`, `cond`, and `uncond` embeddings are
documented and implemented in [Birr0/wwdc_spectra](https://github.com/Birr0/wwdc_spectra):
see its `src/wwdc_spectra/training/train.py`,
`src/wwdc_spectra/inference/embed.py`, and Hydra configurations in `src/conf/`.
This project supports cached embeddings and a CPU checkpoint-inference route
using the pinned upstream implementation. The 32-spectrum comparison passes in
the locked standalone environment, including original, conditional and
unconditional embeddings, redshift and mask ratio.
The inspected upstream revision and provenance limits are in
[docs/PROVENANCE.md](docs/PROVENANCE.md).

The figure commands include the paper frontier, corner plot, fixed-score
equation anatomy, and CMD. An earlier version passed a clean-clone migration
check; subsequent selection and figure changes have their own audit records.
That earlier check is not a certification of every current figure or a
public-input end-to-end run. See [figure definitions](docs/FIGURES.md),
[validation](docs/VALIDATION.md), and [input acquisition](docs/INPUTS.md).
Public hosting for the exact checkpoint, embeddings and archived spectrum
splits remains a release task. Code is licensed under [MIT](LICENSE). Neural training has not been
rerun. A fresh conditional-latent-plus-redshift SR search with seed 42 reproduced
all 23 archived equations, including their 12-decimal exports (2026-10-07,
pyoperon 0.4.0). The original-latent seed-42 search also reproduced all 24
archived equations, including their 12-decimal exports (2026-10-08).
Additional runs of `orig` seed 43 and `orig+z` seeds 42, 43 and 44
verified the fronts used to recover independent training references;
see [the selection audit](docs/SELECTION_AUDIT.md). This does not verify
every arm/seed combination or cross-platform determinism. The search
audit uses the historical search code, vendored and hash-pinned in
`experiments/historical/`. Its separate environment is pinned by
`experiments/rerun_sr.py.lock` and provisioned with `uv run --script --locked`;
see [the experiment instructions](experiments/README.md#seeded-symbolic-search-reproduction).

## Inputs

Supply these outside the Git repository; `data/` and generated `outputs/` are
ignored by Git. The command never downloads inputs.

| Input | Expected layout or role |
| --- | --- |
| Embeddings | `train/`, `val/`, `test/` directories of parquet shards generated by `wwdc_spectra`, with spectrum `id` and `orig`, `cond`, `uncond` columns |
| SDSS specgals | Local astroML `SDSSspecgalsDR8_1.fit.gz` and `_2.fit.gz` in the `--specgals-home` directory |
| galSpecExtra | Local `galSpecExtra-dr8.fits`, retained for the historical catalogue join; its `LGM_TOT_P50` matches the astroML `lgm_tot_p50` target on all retained rows |
| Saved candidate fronts | 18 small CSVs bundled under `artifacts/fronts/`; their SHA-256 hashes are in `artifacts/fronts_manifest.json` |
| CMD cache | Rebuild from five pinned mirror shards with `wwdc-cmd-cache`; see [input instructions](docs/INPUTS.md) |

The program records SHA-256 and byte size of each consumed file in its output
manifest. The exact analysis-input hashes are in `artifacts/analysis_inputs.json`.
Checkpoint/config hashes and upstream revision are pinned in the inference
command. Available `Equation_p12` columns are preserved in the bundled fronts,
but evaluation uses `Equation` to preserve the audited calculation.

## Run the validated frontier

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/). From this directory:

```bash
uv sync --frozen
uv run --frozen wwdc-reproduce \
  --embeddings /path/to/embeddings/7655991_0 \
  --galspec /path/to/galSpecExtra-dr8.fits \
  --specgals-home /path/to/sdss \
  --fronts artifacts/fronts \
  --outdir outputs/frontier-run-01
```

The outputs are `manifest.json`, `checks.json`, `samples.csv`, `candidate_scores.csv`,
`selected_before_test.csv`, `selected.csv`, `curves.csv`, `preprocessing.json`, `sample_ids.csv.gz`, and
`frontier.{png,pdf}`. A run refuses to
overwrite a populated output directory. The expected cleaned split sizes are
352,896 / 44,246 / 44,141 spectrum rows. Spectrum IDs do not cross splits;
the split does **not** guarantee physical-galaxy disjointness.

At each length budget, a separate winner is chosen for each input arm and
search seed using validation R². A printed expression must reproduce its
independent training R² within 1e-6 and evaluate finitely on training and validation.
Historical nonfinite training flags are resolved using native training scores
from verified seeded reruns, bound to the archived front hashes and exact equation
strings in `src/wwdc_repro/recovered_training_scores.json`. The old exporter could
flag both splits after a test failure, so those flags are not eligibility criteria.
Selections are saved in `selected_before_test.csv` before any test expression is
evaluated. The selected exported expressions are then scored on test; `selected.csv`
records `test_status=ok` or `evaluation_failure`. No replacement is selected after
a test failure. A failed seed leaves a gap in the averaged frontier rather than
silently averaging the remaining successful seeds. The shaded frontier area is
the seed range, not a confidence interval. See `curves.csv` columns `n`, `n_finite`,
and `evaluation_failures`. Reported test scores are freshly evaluated from the
exported expressions, rather than copied from historical native-tree scores.

The separate `wwdc-figures` command uses the manuscript's display convention:
hollow triangles fill failed points using the best finite test score at a lower
budget for the same arm and seed. This test-informed display does not change
the selected model or its failure status. See [the figure policy](docs/FIGURES.md#frontier-failure-markers).

This implementation follows the audited calculation in the source workspace.
It checks the sample IDs, candidate counts, and L=24 held-out scores against
independently recorded reference values in `src/wwdc_repro/reference.json`.
It also checks ordered sample-ID hashes before scoring: reordering rows changes
the seeded training draws. `samples.csv` records counts through each join/filter.
See [the data validation review](docs/DATA_REVIEW.md).
The migrated calculations and their limits are recorded in [docs/VALIDATION.md](docs/VALIDATION.md).

## Generate all seven figures

```bash
uv run --frozen wwdc-figures \
  --embeddings /path/to/embeddings/7655991_0 \
  --galspec /path/to/galSpecExtra-dr8.fits \
  --specgals-home /path/to/sdss \
  --selected outputs/frontier-run-01/selected.csv \
  --fronts artifacts/fronts \
  --cmd-cache /path/to/vagc_join.parquet \
  --outdir outputs/figures
```

This writes PNG/PDF figures, numerical summaries/arrays, and a manifest of
input and source-code hashes. `--only` accepts any of `frontier score latent
seed-frontiers anatomy zero-latent cmd weights`; `weights` writes the
LaTeX table of L24 latent weights (`latent_weights.tex`, input by the paper). All output directories must be new
or empty. The [code map and recipes](docs/FIGURES.md) describe each calculation.

## Generate embeddings from the checkpoint

Use the archived spectrum splits and checkpoint layout in [docs/INPUTS.md](docs/INPUTS.md).
The wrapper rejects a changed upstream source, a different checkpoint or
configuration, and unexpected parent split counts.

```bash
git clone https://github.com/Birr0/wwdc_spectra.git /path/to/wwdc_spectra
git -C /path/to/wwdc_spectra checkout 0895b4ed9dbe6815cbe641fd1f936c6d53197aa5
uv sync --frozen --extra inference
uv run --frozen --extra inference wwdc-embed \
  --upstream /path/to/wwdc_spectra \
  --data-root /path/to/data \
  --splits test --limit 32 --batch-size 32 \
  --compare-stored /path/to/embeddings/7655991_0 \
  --outdir outputs/embedding-check
```

The command writes embeddings and compares them with saved rows by spectrum ID.
To generate all splits, omit `--splits test`, `--limit 32`, and `--compare-stored`
and use a new output directory. Full-dataset generation has not been run during
this migration; runtime and maximum error remain unmeasured. Partial outputs
are marked in `embedding_manifest.json` and cannot pass the paper sample checks.

The upstream Spender constructor may download its `sdss_I` encoder artifact
if it is not cached, before the paper checkpoint is loaded strictly. This cache
was available during verification. Downstream analysis reads local files.

## Reproduce the embedding MLP comparison

The matched `orig+z` and `cond+z` probe uses the same cleaned sample and
`lgm_tot_p50` target as the frontier. It fits scikit-learn MLPs with hidden
layers `(64, 32)` for seeds 42, 43 and 44, using 100 maximum iterations and no
early stopping. The final `fit_model_fn` definition in `malmquist_bias.ipynb`
fits the MLP on the full cleaned training split; all eligible test rows are
scored. Other MLP options use the locked scikit-learn defaults. The notebook
also contains an earlier, superseded function with a balanced 5,000-row draw;
that is not the function used by its reported MLP results.

```bash
uv run --frozen wwdc-mlp-probe \
  --embeddings /path/to/embeddings/7655991_0 \
  --galspec /path/to/galSpecExtra-dr8.fits \
  --specgals-home /path/to/sdss \
  --outdir outputs/mlp-probe
```

The command writes per-seed test scores (`scores.csv`), a paired comparison,
arm means and ranges, and `metadata.json` with settings and sample ID
fingerprints. The historical result is about 0.9103 for `orig+z` and 0.9072
for `cond+z` (a 0.0031 R² gap). The validation-selected symbolic frontier has
a larger 0.0288 R² gap on the same target.
